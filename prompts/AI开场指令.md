# AI 开场指令

读一篇新论文前，先把下面这段发给 AI（ChatGPT、Claude、Kimi、DeepSeek 等都可以），再附上 PDF。它的作用是让 AI 等你先写，再来核对。

精读前还可以用 [概念预填指令](概念预填指令.md) 让 AI 先把每章的概念解释填好。

```text
我要用“先闭卷、后反馈”的方式读论文《____》（附 PDF）。请遵守：
1. 我发来某一章的闭卷三问之前，不要解释或总结这一章（背景概念可以讲，本章的结论和新概念不要讲）；
2. 我卡在某个概念时，只讲理解本文所需的深度，并先让我写一行自己的猜测；
3. 我发来闭卷内容后，依据原文指出：哪些对、哪些错、哪些漏了、哪些缺证据位置，先追问再给提示；
4. 不要替我重写笔记，也不要提前解读我还没读到的章节；
5. 你的每条修正都标出论文中的位置，方便我回原文核实。
```

## 一章读完后

```text
这是我闭卷写的本章理解：____。请依据论文指出哪些正确、哪些不准确、哪些遗漏、哪些缺少证据位置。先追问让我自己修正，再给提示。不要提前写后面章节的解读。
```

## 全文读完后

```text
我已经先独立阅读论文并完成下面的笔记。请把论文原文作为证据源，不要用常识替论文补全，也不要替我重写笔记。

请按“问题—证据—判断—验证任务”检查：
1. 找出事实错误、概念误解和遗漏；
2. 检查关键判断是否有页码、章节、公式或图表证据；
3. 区分作者结论、我基于论文的归纳和超出论文的新推断；
4. 指出实验能证明什么、不能证明什么，检查过度推断；
5. 对含糊之处先追问，再给提示；
6. 最后给出3个自测题（只出题，不给答案，我一周后不看笔记再答）和1～3个可执行的验证任务。
```

更多提问模板（概念、段落、公式）见 [使用说明](../docs/论文阅读-使用说明.md#六ai-提问模板)。
