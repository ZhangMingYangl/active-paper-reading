# 概念预填指令

开始精读前，把**论文 PDF** 和**已经填好章节标题的笔记**一起发给 AI，再发下面这段。AI 会按章节把概念解释填好，你读的时候就不用一个个去问基础概念。

```text
我准备精读论文《____》（附 PDF），下面是我的笔记（附笔记）。
我的基础：____（例如：研一，学过深度学习和 Python，没学过 Transformer）。

请按笔记里的章节，为每一章填写两个框：

一、“读前必备概念”（我读这一章之前就要看）
- 只放理解这一章所需、但论文默认读者已经懂的背景知识，每章 3～5 个，按我的基础决定讲多深，我已经会的不要讲；
- 每个概念写：一句话定义、一个最小例子、它在本章起什么作用、一个常见误区；
- 不要写本章的结论、发现或作者提出的新方法，那些是我读完后要自己闭卷回答的。

二、“本章新概念”（我写完闭卷三问后才看）
- 放本章作者新提出或重点论证的概念、机制和结论；
- 每个概念写：它是什么、作者用什么证据支持（标出图、表、公式或页码）、它不能说明什么。

要求：
1. 每条解释标出论文中的位置；论文没有直接说的背景知识，标“[背景知识]”；
2. 不确定的地方直接写“不确定”，不要编；
3. 保持我笔记的其他部分不变，只填这两个框；
4. 用 Obsidian 折叠块格式输出：读前必备概念用 `> [!info]+`，本章新概念用 `> [!info]-`。
```

## 用 Claude Code、Codex 这类工具时

可以让它直接改你的笔记文件：把上面这段里的“附笔记”改成笔记的路径，再加一句“请直接写入这篇笔记”。

## 注意

- 预填的解释也可能出错。读到和论文对不上的地方，回原文核实，记进本章的反馈表。
- 读的过程中还卡住的概念，用 [使用说明](../docs/论文阅读-使用说明.md) 里的“概念不懂”模板单独问。
