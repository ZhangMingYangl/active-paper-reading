# 论文阅读-类型模块

> [!important] 怎么用
> 快速浏览后判断论文类型，选 1～2 个模块，把问题粘到笔记的“全文整合 → 类型模块问题”，逐条作答，不适用的写 N/A。混合型论文（例如 benchmark + 机制 + 方法）选最主要的两个。
> 这些问题还在试用中，会根据大家的阅读复盘持续修改，改动记录见 [CHANGELOG](../CHANGELOG.md)。
> 流程与规则见 [论文阅读-使用说明](论文阅读-使用说明.md)。

## 方法 / 模型

1. 作者新提出的部分是什么？哪些只是已有组件的组合？
2. 能否把输入 → 核心过程 → 输出画成一条流程？
3. 最强、最新的基线是否都比了？设置是否公平（同数据、同预算、同调参力度）？
4. 消融是否逐个去掉了新增模块？每个模块贡献多少？
5. 计算、显存、时延成本是否报告？
6. 关键超参数变化时结果稳定吗？
7. 在哪些数据或设置上没有提升，甚至变差？

## Benchmark / 实证分析

1. 自变量和结果变量分别是什么？每张表只改变了哪一个？
2. 覆盖的模型、任务和规模，是否足以支撑结论的范围？
3. 指标是否测到了研究真正关心的东西？评测器（包括 LLM 裁判）可能有什么偏差？
4. 结论是否写成了有条件的（“在 X 设置下”）？有没有被忽略的反例？
5. 是否有重复实验、方差或显著性检验？
6. 数据和代码是否公开，能否复现？

## 攻击 / 防御（安全）

1. 威胁模型：攻击者能看到什么、能改什么、知道多少（白盒 / 黑盒）？
2. 安全目标是什么？攻击“成功”怎样定义、由谁判定？
3. 防御类论文：是否测试了知道防御存在的自适应攻击？
4. 安全收益的代价：正常任务能力、时延、成本下降了多少？
5. 结论在不同模型、不同规模上是否都成立？
6. 对比的攻击或防御是否最新，设置是否一致？
7. 这个威胁模型在真实部署中是否成立？

## 机制 / 可解释性

1. 要解释的现象是什么？现象本身是否先被确认？
2. 证据是相关性的（可视化、相似度），还是干预性的（消融、修补、因果实验）？
3. 可视化（t-SNE、注意力图）有没有被当作单独的证据？
4. 机制能否给出可证伪的预测，并被另一个实验检验？
5. 在其他模型上是否也观察到同样的机制？

## 系统 / 效率

1. 优化的是哪个瓶颈（显存、吞吐、时延、通信）？
2. 硬件、批量大小、序列长度等条件是什么？
3. 效率指标是端到端的，还是只测了单个算子？
4. 效率提升以多少质量损失为代价？
5. 与真实部署环境差多少？

## 数据集 / 资源

1. 数据来源、构造流程、标注方式和质量控制是什么？
2. 是否可能与模型训练数据重叠或泄露？
3. 分布偏差、覆盖范围和使用许可如何？
4. 现有方法在这个数据集上的结果是否拉得开差距（有没有区分度）？

## 综述

1. 分类框架是什么？类别之间是否自洽、不重叠？
2. 文献覆盖范围和截止时间是什么？
3. 作者总结的开放问题有没有依据？
4. 哪些对比是作者自己做的，哪些只是转述？

## 理论

1. 关键假设是什么？现实中是否成立？
2. 定理到底保证了什么，没保证什么？
3. 理论结论与实验是否对得上？
4. 界是否足够紧，常数能否忽略？
