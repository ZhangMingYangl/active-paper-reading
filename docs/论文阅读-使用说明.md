# 论文阅读-使用说明

> [!important] 这份说明和母版的关系
> [论文阅读-主动思考模板](../templates/论文阅读-主动思考模板.md) 只放每篇论文都要填的栏目；规则、方法和 AI 提问模板都放在这里，改一次所有笔记都生效。
> 按论文类型补充的问题见 [论文阅读-类型模块](论文阅读-类型模块.md)。

## 一、三者分工

- **PDF 是证据源。** 定义、公式、实验、图表和结论都回原文核对。
- **Obsidian 留下我的理解。** 笔记不是翻译稿。
- **AI 负责解释、追问和校验。** 不替我阅读，也不替我写闭卷内容。

最重要的一条：**先自己闭卷写，再找反馈。** AI 的解释和核对放在折叠块里，写完闭卷内容后再展开。

## 二、每篇论文的固定流程（母版生成流程）

```text
1. 复制母版，填阅读目的
↓
2. 快速浏览，判断论文类型，从类型模块中选 1～2 个，粘到“全文整合”
↓
3. 选 2～3 个核心章节，把“精读”块的标题换成原文真实章节
↓
4. 闭卷初读三句话 → 核心章节走小循环，其他章节写一句话 → 全文整合 → 最终判断
↓
5. 写 3 行复盘，写好 3 道自测题；一周后不看笔记作答
↓
6. 每读 3～5 篇，按复盘修改母版和类型模块
```

快速浏览路线：标题 → Abstract → Introduction 末尾的贡献 → 章节标题 → 主要图表 → Conclusion。只记关键词、1～3 张重要图表和陌生概念，不卡在公式里。

## 三、每章小循环

只有 2～3 个核心章节走完整循环；其他章节读完合上论文写一句话。每章都走一遍太重，很难坚持读完全文。

```text
预测（1行） → 阅读 → 合上论文写闭卷三问 → 对照原文修正 → 记录反馈
```

- **闭卷三问**：这章回答什么问题？作者的答案和证据？我还没懂什么？
- **对照原文**写的是“我错了什么、漏了什么”，不是把原文翻译过来。
- **反馈记录**的四种来源：自我（闭卷对比）、证据（原文/图表）、外部（AI/同学/老师）、实践（复现、反例）。AI 的每条修正都要回原文核实，核实后再勾 ✅。
- **质疑不知道怎么写时**，任选一个起步问题：样本或任务够吗？基线公平吗？这是相关还是因果？换个模型或场景还成立吗？结论有没有超出实验范围？

## 四、记录规则

- `[原文]`：论文明确写出，或图表直接显示的内容。
- `[我的理解]`：我根据论文内容，用自己的话归纳出的判断。
- `[我的质疑]`：我认为尚未被充分证明或解释的地方。
- `[我的启发]`：由论文触发、但超出作者结论的新想法。
- `论文未说明`：应该报告但作者没有报告。
- `当前证据不足`：我还没找到足够证据。
- `N/A`：确实不适用。

重要判断尽量附证据位置：`p.页码 / §章节 / Fig.图 / Table表 / Eq.公式`。

## 五、概念学习闭环

### 1. 先分类

| 类型 | 判断方法 | 处理方式 |
|---|---|---|
| 必须立即学习 | 不懂就无法继续理解当前句子、图或公式 | 暂停，只学到能够继续阅读的深度 |
| 读到对应章节再学习 | 只影响后面的局部内容 | 先标记，作者正式使用时再学 |
| 暂时跳过 | 模型名、引用或实现细节，不影响主线 | 放入待补列表，读完本章再判断 |

### 2. 学习步骤

精读前先用 [概念预填指令](../prompts/概念预填指令.md) 让 AI 按章节填好两类概念：

- **读前必备概念**（默认展开）：论文默认读者已经懂的背景知识，读这一章前先看；
- **本章新概念**（默认折叠）：作者在本章提出或论证的内容，是闭卷三问的答案，写完闭卷三问再展开。

预填之外还卡住的概念，按下面的步骤学：

```text
先写一行自己的猜测
↓
问 AI 或查教材
↓
合上解释，用自己的话复述
↓
举一个最小例子
↓
回论文重读原句，说明它在本文中的作用
```

### 3. 学会的最低标准

不看解释也能用自己的话说明；能给出一个最小例子；能指出它在本文中的作用；能回答一个变化或反例问题。只觉得“看懂了”还不算掌握。

### 4. 概念学习卡（深读时复制到当前章节）

```md
##### 概念：________

- 我的初始猜测：
- 它解决什么问题：
- 输入、核心过程和输出：
- 最小例子：
- 它在本文中的作用：
- 与相近概念的区别 / 常见误区：
- 闭卷自测题与结果：已掌握 / 仍需补充
- 来源：
```

## 六、AI 提问模板

### 概念不懂

```text
我正在阅读《____》，卡在“____”。请只讲理解当前论文所需的深度：它解决什么问题、输入/过程/输出、一个最小例子、在本文中的作用和一个常见误区。解释后先问我3个检查理解的问题，等我回答后再纠正。请把解释写成 Obsidian 折叠块（> [!info]-），不要直接改我的闭卷内容。
```

### 段落不懂

```text
请解释这段话的因果关系，不要只翻译。区分前提、作者的操作、观察到的结果和作者据此作出的判断。
```

### 公式不懂

```text
先说明这个公式解决什么问题，再解释每个变量，给一个最小数值例子，最后说明它在整个方法中的位置。
```

### 一章读完后

```text
这是我闭卷写的本章理解：____。请依据论文指出哪些正确、哪些不准确、哪些遗漏、哪些缺少证据位置。先追问让我自己修正，再给提示。不要提前写后面章节的解读。
```

### 全文读完后

```text
我已经先独立阅读论文并完成下面的笔记。请把论文原文作为证据源，不要用常识替论文补全，也不要替我重写笔记。

请按“问题—证据—判断—验证任务”检查：
1. 找出事实错误、概念误解和遗漏；
2. 检查关键判断是否有页码、章节、公式或图表证据；
3. 区分作者结论、我基于论文的归纳和超出论文的新推断；
4. 指出实验能证明什么、不能证明什么，检查过度推断；
5. 对含糊之处先追问，再给提示；
6. 最后给出3个自测题（只出题，不给答案，我一周后不看笔记再答）和1～3个可执行的验证任务。
```

## 七、AI 的边界

- 闭卷内容由我写；AI 的解释和核对放在折叠块里，紧邻我的原答，不覆盖原答。
- 我还没读到的章节，AI 不提前写解读。
- AI 回答流畅不代表正确，确认前要回原文核对。
- 迁移到自己研究方向的想法，标为 `[我的启发]` 或“基于论文内容的推断”，不写成论文结论。
