# 让 AI 自动部署

不想手动设置的话，可以让能操作电脑文件的 AI 编程助手帮你装好。例如 Claude Code、Codex、Cursor、Trae、Windsurf 等，它们能读写本地文件、运行命令。

普通聊天网页（只能对话、不能动你电脑上的文件）做不了这件事，请按 [新手操作教程](01-新手操作教程.md) 第 0 步手动设置。

## 方法一：一句话交给 AI（推荐）

打开 AI 编程助手，把下面这句话复制过去：

```text
请按 https://github.com/ZhangMingYangl/active-paper-reading 里 AGENTS.md 的说明，把这个论文阅读母版装进我的 Obsidian 知识库。
```

AI 会先问你知识库在哪个文件夹，再预演一遍告诉你会改什么，你确认后它才会真正修改。它不会删除或覆盖你已有的笔记和设置。

## 以后怎么更新

我们更新了母版，你这边**已经写好的论文笔记不受影响**：每篇笔记是母版复制出来的一份，规则也写在笔记里。要更新的只是装进知识库的母版和说明文档，以后新建的笔记就用新版。

- **让 AI 更新：** 对 AI 编程助手说一句：

  ```text
  请按 https://github.com/ZhangMingYangl/active-paper-reading 里 AGENTS.md 的说明，把我 Obsidian 知识库里的论文阅读母版更新到最新版。
  ```

- **自己更新：** 下载最新的仓库，运行 `python setup.py --vault "<知识库路径>" --update`（可以先加 `--dry-run` 预演）。

你没改过的文件会直接换成新版；你改过的文件，旧内容会先备份到 `论文阅读/备份/<时间>/`，不会丢。

**想在有新版时收到通知：** 在仓库页面右上角点 **Watch → Custom**，勾选 **Releases**。

## 方法二：自己运行安装脚本

电脑上装了 Python 3 的话，下载本仓库后，在仓库文件夹里打开终端运行：

```bash
# 先预演，只显示会做什么
python setup.py --vault "D:/Obsidian/我的知识库" --dry-run

# 确认没问题后正式安装
python setup.py --vault "D:/Obsidian/我的知识库"
```

可选参数：

| 参数 | 作用 |
|---|---|
| `--folder 名字` | 装到知识库里的哪个文件夹，默认 `论文阅读` |
| `--force` | 覆盖已存在的同名文件（默认不覆盖） |
| `--dry-run` | 只预演，不修改 |

## 脚本会做什么

1. 把 `templates/ docs/ prompts/ examples/` 复制到 `<知识库>/<文件夹>/`；已有同名文件默认跳过。
2. 在 `.obsidian/core-plugins.json` 里开启 Obsidian 的“模板”核心插件。
3. 如果你还没设置模板文件夹，就设为 `<文件夹>/templates`；如果已经设置了别的模板文件夹，不改设置，只把母版复制一份进去。
4. 修改配置前，自动把原文件备份为 `core-plugins.json.bak`、`templates.json.bak`。

## 装好之后

1. 新建一篇笔记，按 `Ctrl/Cmd + P`，输入“模板”，选 **模板：插入模板 → 论文阅读-主动思考模板**。
2. 找不到母版的话，**完全关闭并重新打开 Obsidian** 再试。
3. 从 [新手操作教程](01-新手操作教程.md) 的第 1 步开始读你的第一篇论文。

## 出问题了

- **提示“没有 .obsidian 文件夹”**：路径不是知识库根目录，或者这个知识库还没用 Obsidian 打开过。先用 Obsidian 打开一次再运行。
- **插入模板时找不到母版**：先完全关闭并重新打开 Obsidian；再到“设置 → 模板”看模板文件夹设成了哪里。
- **想撤销**：删掉安装的文件夹，把 `.bak` 文件改回原名；没有对应 `.bak` 的配置文件，说明安装前不存在，直接删掉即可。
