# 主动阅读论文：10 分钟快速上手

> 试用版。目前只在我自己读论文时用过，欢迎试用后告诉我哪里不好用。

## 这套方法解决什么问题

读论文时最常见的情况是：看一句、问一次 AI、复制回答。笔记写了很多，合上论文却讲不清楚。
开题、中期、答辩这些正式反馈间隔太长，所以要在每次读论文时自己制造高频反馈：

> **先合上论文，自己写；再拿原文和 AI 来对照、纠错。**

一篇 PDF 是证据源，一份笔记留下你自己的理解，AI 只负责解释、追问和校验，不替你读。

## 读一篇论文的六步

1. **复制母版**，写下为什么读这篇（3 行）。
2. **快速浏览 10～20 分钟**：标题 → 摘要 → 引言末尾的贡献 → 章节标题 → 主要图表 → 结论。判断论文类型，从类型模块里选 1～2 个。
3. **合上论文写三句话**：研究什么、做了什么、我最需要核对什么。写错没关系，这是第一版理解。
4. **核心章节走小循环**：选 2～3 个核心章节（通常是方法和实验），每章预测 → 阅读 → 合上论文回答三问（这章回答什么问题？作者的答案和证据？我没懂什么？）→ 回原文找出自己错了什么 → 再让 AI 核对，记在反馈表里。其他章节读完合上论文写一句话。
5. **读完写最终判断和 3 行复盘**：哪些栏目空着、哪些问题真的有用、这篇用了多久。再写 3 道自测题，先不答。
6. **一周后回忆**：不看笔记回答那 3 道题，再翻回笔记核对，答不上来的就回看。

## 和 AI 配合：开场先发指令

读一篇新论文前，先把 [AI 开场指令](../prompts/AI开场指令.md) 里的那段话发给 AI，再附上 PDF。它会让 AI 等你先写完闭卷三问再核对，不会一上来就把答案给你。精读前还可以用 [概念预填指令](../prompts/概念预填指令.md) 让 AI 填好精读章节的背景概念。

## 常见问题

- **概念全都不懂怎么办？** 只学“不懂就读不下去”的那几个，其他的先标记。概念解释放在折叠块里，先写一行自己的猜测再展开。
- **每个栏目都要填吗？** 不用。只有 2～3 个核心章节走完整循环，其他章节写一句话；标了“深读可选”的部分可以删掉。
- **质疑写不出来？** 从四个起步问题里任选一个：样本够吗？基线公平吗？是相关还是因果？换个模型还成立吗？
